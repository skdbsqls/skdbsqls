- 사용자 입장에서 서비스의 흐름과 불편을 살피며 화면을 구현합니다.

## 🚀 Projects

### DocCo

**AI 기반 팀 프로젝트 어시스턴트**

- React와 TypeScript 기반 프론트엔드 개발
- SSE 기반 문서 탐색·답변 생성·도구 호출 단계별 UI 구현
- API 응답 데이터 가공 및 로딩·완료·오류 상태 처리
- 프론트엔드 리드 및 RAG 성능 개선 과정 참여

### 메아리

**WebRTC 기반 온라인 교육 기부 플랫폼**

- 멘토·멘티·관리자 화면 및 실시간 수업 UI 구현
- 화면 공유, 양방향 주석, 실시간 채팅 기능 개발
- Atomic Design 기반 공통 컴포넌트 설계
- Figma, Notion, Jira를 활용한 협업 기준 문서화

### Mango

**React Native 기반 모바일 매칭 서비스**

- 프로필 조회, 스와이프, 매칭, 실시간 채팅 흐름 구현
- 읽지 않은 메시지 수 및 채팅 상태 동기화
- 신고·차단 기능과 관련 화면 개발
- Android 빌드 과정에서 발생한 설정 문제 해결

### FitFinder

**공공체육시설 프로그램 맞춤형 추천 서비스**

- 사용자 조건 기반 프로그램 추천 및 필터 기능 구현
- 현재 위치 기반 거리 계산과 카카오 지도 연동
- 무한스크롤을 적용해 프로그램 탐색 경험 개선
- 공공데이터 활용 경진대회 우수상 수상
